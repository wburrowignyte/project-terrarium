# Program overview (synthetic)

## Application lifecycle
Submitted → In Review → Pending Verification → Approved / Denied / Withdrawn.
Approved applications create a Case.

## Eligibility inputs
- Household income (monthly, by source: wages, self-employment, child support, other)
- Household size
- Activity of each adult (employment, education, job search) with weekly hours

## Security
Workers may only access applications and cases belonging to their county.
Applicant SSN and date of birth are collected and must be restricted to eligibility workers.

## Volumes
Roughly 40,000 applications per year statewide; cases are retained for 7 years after closure.
