# Glossary — Child Care Assistance (synthetic)

| Term | Meaning | Avoid |
|---|---|---|
| Household | The family unit applying for assistance. One household per application. | Family, client |
| Applicant | The adult in the household who signs the application. | Primary |
| Child | A household member under 13 (or under 15 with special needs) for whom care is requested. | Kid, dependent |
| Application | A request for assistance submitted by a household. Has a status lifecycle. | Case (a case is created only after approval) |
| Case | An approved, ongoing assistance authorization for a household. | |
| Provider | A licensed or legally non-licensed child care provider. | Vendor |
| Authorization | Approval for a specific child to receive care from a specific provider for a date range and number of hours. | Voucher |
| Worker | County staff member who processes applications and manages cases. | Caseworker (synonym, acceptable) |
| County | The administering county. Workers only see applications/cases in their county. | |
